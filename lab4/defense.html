Код для показу

Підключення до API. lab4/MauiProgram.cs:11 (рядки 11–14).

var api = DeviceInfo.Platform == DevicePlatform.Android ? "https://10.0.2.2:7080/" : "https://localhost:7080/";
builder.Services.AddSingleton(new HttpClient(DevHandler())
    { BaseAddress = new Uri(api), Timeout = TimeSpan.FromSeconds(15) });
builder.Services.AddSingleton<ApiClient>();

Указую адресу API з ЛР 3. Для Android 10.0.2.2 веде з емулятора до сервера на комп’ютері.

Той самий клієнт використовує localhost у Windows і спеціальну адресу хоста в Android-емуляторі. Адресу налаштовую в одному місці. Екрани входу й завдань працюють через спільний ApiClient.

Оновлення списку. lab4/ViewModels.cs:75 (рядки 75–78).

bool? done = Filter switch { 1 => false, 2 => true, _ => null };
var items = await api.GetTasksAsync(Search, done, Sort switch { 1 => "-priority", 2 => "title", _ => "due" });
Tasks.Clear();
foreach (var t in items) Tasks.Add(t);

Передаю пошук, фільтр і сортування в API. Коли приходить відповідь, замінюю список на екрані. Це видно, коли вводжу «лр».

Екран прив’язаний до списку у ViewModel. Після відповіді сервера колекція оновлюється, а список перемальовується. Кнопки й поля керують запитом, а отримані дані відображаються на екрані.

1. Вхід на Android і Windows. Перемкнися на Android. У полях «Логін» і «Пароль» введи тестові дані, натисни «Увійти». Спочатку покажи повідомлення з неправильним паролем, потім увійди правильно. У Windows натисни «Увійти» з правильними даними й відкрий список.

На екрані входу вводжу навчальний логін із термінала. Спочатку пробую неправильний пароль і натискаю «Увійти». Під полями з’являється повідомлення про помилку, бо API повернув 401.

Повторюю вхід із правильним паролем. Відкривається екран «Мої завдання». Над пошуком бачимо ім’я користувача, а у списку — його завдання. Клієнт отримав токен і використав його для запиту списку.

2. Пошук, фільтр і сортування. В Android натисни пошук, введи «лр», підтвердь з клавіатури. Далі вибери «Усі» й сортування за пріоритетом. Покажи той самий екран у Windows і зміни ширину вікна, щоб було видно адаптацію.

У полі «Пошук за назвою або описом» вводжу «лр» і підтверджую пошук на клавіатурі. Список стає коротшим. У ньому залишаються завдання, у яких цей текст є в назві або описі.

Під пошуком два поля. У фільтрі обираю «Усі». Тепер бачимо також виконані завдання. У сортуванні обираю порядок за пріоритетом, і картки міняються місцями. Після цього очищаю пошук і підтверджую його ще раз, щоб повернути повний список.

На Android бачимо екран застосунку в емуляторі, а у VirtualBox — його Windows-версію. Обидва клієнти завантажують дані через REST API. У кожного середовища свій локальний сервер і своя база, тому результати перевіряємо окремо.

Показ результату

3. Повний цикл із завданням. На Android натисни «＋ Завдання», заповни форму й вибери проєкт, якщо потрібно. Після спроби з короткою назвою створи «Демо Android». У Windows повтори з назвою «Демо Windows». На кожній платформі відкрий картку, зміни статус і видали запис.

Натискаю «＋ Завдання». У полі «Назва» вводжу «x» і натискаю «Зберегти». Біля кнопки з’являється повідомлення, що назва закоротка. Форма залишається відкритою, тож одразу виправляю назву й зберігаю.

У списку відкриваю нове завдання. Натискаю «Редагувати», вмикаю перемикач «Виконано» і зберігаю. У деталях тепер видно «Виконано ✓». Якщо натиснути «Видалити» й підтвердити, запис зникне зі списку після відповіді API.

4. Помилка з’єднання. Повернися в термінал Mac і натисни Enter на запрошенні «зупинити API». В Android потягни список униз для оновлення. Дочекайся повідомлення про недоступний сервер.

У терміналі з’явилося «API зупинено». Повертаюся до списку завдань в емуляторі й тягну його вниз, щоб оновити. Над списком бачимо «Сервер недоступний».

Додаток залишається відкритим. Повідомлення з’являється тому, що запит на оновлення більше не може зв’язатися з API.

Завершення показу. Натисни Enter у терміналі Mac. У Windows закрий клієнт і натисни Enter у вікні Start Lab 4.cmd, щоб зупинити API у віртуалці.
