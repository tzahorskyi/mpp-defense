Перед захистом. Запусти Docker Desktop. Збирання та підняття контейнерів може зайняти додатковий час.

cd ~/Desktop/unik/MPP
./demo.sh 5

Доброго дня. Я Тарас Загорський, група ІПЗ-31. У п’ятій лабораторній упакував API у Docker. Dockerfile збирає образ, а compose.yaml запускає API і PostgreSQL разом.

1. Enter → Dockerfile. Покажи два етапи збірки в терміналі.

Перший етап збирає .NET-застосунок. Другий запускає готовий застосунок у меншому образі з середовищем виконання.

2. Enter → Docker Compose. Дочекайся статусів контейнерів.

Compose запускає PostgreSQL, чекає на готовність бази й запускає API.

Показ результату

3. Enter → перевірка API. Покажи відповідь /health і завдання «ЛР5 Docker» у виводі PostgreSQL.

Перевірка стану пройшла. Через API створив завдання, а запит до PostgreSQL підтверджує, що воно записалося в базу.

4. Enter → перезапуск. Дочекайся повторного пошуку завдання.

Після перезапуску контейнерів завдання лишилося. Дані PostgreSQL зберігаються в Docker volume.

5. Enter → дві архітектури. Покажи linux/arm64, linux/amd64 та результати uname.

Один тег образу підтримує дві платформи. Запуск на arm64 показує aarch64, запуск на amd64 — x86_64.

Дякую за увагу.
